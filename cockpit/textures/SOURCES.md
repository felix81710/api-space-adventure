# Earth surface and clouds

Local copies of the Earth textures used by the official Three.js fly-controls Earth example:

- https://github.com/mrdoob/three.js/blob/dev/examples/misc_controls_fly.html
- https://github.com/mrdoob/three.js/blob/dev/examples/textures/planets/earth_atmos_2048.jpg → earth-surface.jpg
- https://github.com/mrdoob/three.js/blob/dev/examples/textures/planets/earth_clouds_1024.png → earth-clouds.png
- https://github.com/mrdoob/three.js/blob/dev/examples/textures/planets/earth_specular_2048.jpg → earth-specular.jpg

Retrieved 2026-10-23. The repository license is included in THREE-LICENSE.txt. The game loads these local files and does not contact external texture services.
