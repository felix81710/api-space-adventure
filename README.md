# 阿屁的太空冒險

[進入駕駛艙](https://felix81710.github.io/api-space-adventure/)

適合親子一起探索的太空冒險。包含 3D 駕駛艙、量子引擎、船體維修、行星字母燃料補給，以及隕石攔截、無人機攔截和太空打撈。

建議使用 iPad 橫向遊玩。遊戲進度保存在目前瀏覽器與網站網址；更換裝置或瀏覽器不會自動同步。
